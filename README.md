# CareVault — Family Health OS

**Tagline:** Your family's health, organized for life.

CareVault is a hackathon-ready healthcare MVP focused on family health organization and care navigation.

## What is included

- Family health dashboard
- Family member profiles
- Health Vault for prescriptions, lab reports, discharge summaries, vaccination and insurance documents
- AI document-summary experience
- AI assistant / RAG-style interaction using demo family records
- Doctor visit preparation
- Hospital discovery and comparison
- Doctor discovery
- Insurance comparison framework
- Illustrative healthcare cost planner
- Pharmacy finder
- Emergency access mode
- Global search
- Responsive premium healthcare UI
- Demo data and safety disclaimers

## Run locally

This version intentionally has **no build step and no dependencies**.

1. Download/unzip the project.
2. Open `index.html` in Chrome/Edge.

For GitHub Pages, push the three website files (`index.html`, `style.css`, `app.js`) to a repository and enable Pages.

## Important

This is a prototype using fictional data. It does not diagnose disease, prescribe treatment, replace a doctor, or provide real-time emergency services. Real deployment would require secure authentication, encrypted storage, consent/access controls, verified healthcare data sources, real maps/hospital APIs, and a production-grade AI/RAG backend.

## Suggested hackathon demo flow

1. Overview → show family dashboard.
2. Health Vault → open a report and show AI summary.
3. AI Assistant → ask "What health information do we have for Dad?"
4. Doctor Visit Prep → generate a visit checklist.
5. Hospitals → show care navigation criteria.
6. Insurance → demonstrate cost planner.
7. Emergency → show one-tap family context.
